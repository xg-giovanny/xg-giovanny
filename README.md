### 💼 Casos de Estudio Empresariales

> *Desarrollos de alto impacto construidos bajo políticas de confidencialidad (NDA).*

#### 🔐 1. Sistema Integrado de Gestión Empresarial (ERP / S.I.G.E.)
*Plataforma centralizada para la planificación de recursos, gestión vehicular y control de capacidad operativa en sectores de energía y telecomunicaciones.*
* **Capacidades Multi-Tenant:** Rediseño modular para el seguimiento de personal operativo y auditoría en tiempo real en grandes cuentas de infraestructura.
* **Módulo de Logística Vehicular:** Gestión de mantenimiento de flotas, trazabilidad de Órdenes de Trabajo (OT) por placa y parametrización de centros de costos.
* **Seguridad Granular:** Sistema de permisos por roles (RBAC) con vistas condicionales e integración de reportes dinámicos en PDF/Excel.
* **Stack:** `Python (FastAPI)`, `Vue.js 3 (PrimeVue / TailwindCSS)`, `MySQL`, `Docker`.

#### 🗺️ 2. Plataforma Geoespacial Logística de Almacén & Cuadrillas
*Sistema transaccional de alta concurrencia para el control de inventarios y traslados de personal.*
* **Contribución Core:** +300 commits, +55.000 líneas de código y gestión de más de 1.000 archivos del sistema.
* **Enrutamiento Geoespacial:** Mapas interactivos con *Leaflet* para monitoreo de cuadrillas, traslados masivos de órdenes y filtrado en tiempo real.
* **Control de Concurrencia:** Optimización de consultas SQL en MariaDB y prevención de bloqueos por edición simultánea de planillas de trabajo.
* **Stack:** `Node.js (Express)`, `Vue 3 (Quasar Framework)`, `Leaflet GIS`, `MariaDB`.

#### 🌐 3. Portal Corporativo & Optimización Web (Core Web Vitals)
*Plataforma de presentación institucional con arquitectura de componentes dinámicos e interfaz adaptable.*
* **Sincronización UI Avanzada:** Acoplamiento bidireccional entre instancias de *Swiper.js* y pestañas de *Bootstrap 5* sin pérdida de estado.
* **Optimización de Rendimiento:** Compresión y conversión de activos a formato `WebP`, carga diferida (`lazy-loading`) y recursos precargados para reducir tiempos de carga en dispositivos móviles.
* **Stack:** `JavaScript (ES6+)`, `Bootstrap 5`, `CSS3 Moderno`, `Swiper.js`.
